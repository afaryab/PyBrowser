# Changelog

All notable changes to PyBrowser will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2024-01-28

### Added
- Initial release of PyBrowser
- OAuth 2.0 authentication with secure token storage
- Team and application management
- Quick links functionality
- Cross-platform support (Windows, macOS, Linux)
- PyQt6-based user interface
- Main browser window with sidebar and web view
- Login dialog with OAuth flow
- API client for backend communication
- Pydantic data models for type safety
- Comprehensive test suite
- CI/CD workflows with GitHub Actions
- Build and release automation for all platforms
- Security scanning with CodeQL, Safety, and Bandit
- Code quality checks (Black, Flake8, mypy)
- GitHub Copilot instructions for development
- Complete documentation and setup guides

### Security
- Secure credential storage using system keyring
- HTTPS-only API communication
- Input validation with Pydantic models
- OAuth 2.0 authorization code flow
